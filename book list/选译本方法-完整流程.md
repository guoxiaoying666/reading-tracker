# 经典儿童文学译本选择方法 —— 完整流程

> 用于「译本评测」web 应用的后端逻辑。
> 此方法已在实践中验证：完成 38 本候选书目的筛选、6 篇已发布评测。
> 每一步都解决一个具体问题，最终输出「一书一结论」的推荐方案。

## 第0步：定义边界（解决：什么书值得做？）

### 核心原则
只做**外国经典儿童文学**的中文译本评测。不是所有有译本的翻译书都做。

### 入选条件
1. **外国作品** —— 排除中国原创
2. **经典儿童文学** —— 百年流传、公认名著（非畅销书、非单季爆款）
3. **至少2位不同的译者**有大陆独立单本在售 —— 如果全网只剩1位译者在印，评测没有意义
4. **译者之间无代差** —— 各译本都有一定流通度和口碑，不是"一个人垄断90%市场"

### 排除条件
| 排除类型 | 示例 |
|---------|------|
| 只剩1位译者有书在售 | 《窗边的小豆豆》只剩赵玉皎1人 |
| 译者全部存疑 | 《杜立德医生》《兔子坡》找不到可靠版本 |
| 非儿童文学 | 《百年孤独》《追风筝的人》 |
| 中国原创 | 《仙女的孩子》非内斯比特作品 |
| 台版/港版 | 林良译《狐狸爸爸万岁》（台湾天下文化） |

### 数据范围
- **出版时间**：2000年及之后有出版/再版（确保家长现在买得到）
- **地域**：中国大陆正式出版（排除台版、港版）
- **装帧**：独立单本（非丛书中的一卷）

## 第1步：初筛候补（解决：从海量图书中找到可做的标的）

### 做什么
从一张大的经典书目中，逐一标注是否属于"多译者"状态。

### 输入
- 经典儿童文学书单（例如纽伯瑞奖清单、国际安徒生奖作者清单、中小学必读书目）
- 或者直接的用户候选清单

### 操作
对每本书，先凭已知知识或快速搜索判断译者状况：

```
这本书有几个译者在大陆有单本？

A. 只有1位主流译者（其他市场极小）  → 进入A类（暂不评测）
B. 有2+位译者各占一定市场          → 进入B类（进入候选）

例子：
- 《夏洛的网》→ 任溶溶占主流90%，康馨/肖毛有书但市场小 → A类 → 暂不优先
- 《海底两万里》→ 曾觉之、陈筱卿、郑克鲁、赵克非、沈国华等多位平分秋色 → B类 → 纳入候选
```

### 输出
一份候选清单，格式为：

```
书名：海底两万里
候选译者：曾觉之 / 陈筱卿 / 赵克非 / 郑克鲁 / 汪涛 / 沈国华
状态：候选待核实
```

## 第2步：豆瓣核验（解决：确认这个译者的版本真实存在且能买到）

### 原理
豆瓣图书页是最快、最集中地展示译者版本信息的地方。一个译者如果豆瓣都没有独立条目，大概率不存在大陆正式版本。

### 操作流程

#### 2a. 搜索译者版本
在豆瓣搜索页 `https://book.douban.com/subject_search?search_text={书名}+{译者}`，获取搜索结果列表。

#### 2b. 提取 subject ID
从搜索结果HTML中，正则提取所有 subject ID（`/subject/\d+/`）。

#### 2c. 访问图书页
逐条访问 `https://book.douban.com/subject/{subject_id}/`。

#### 2d. 提取关键字段
从图书页读取：
- **译者**（info 区域）
- **出版社**
- **出版年**
- **ISBN**
- **定价**
- **装帧**（平装/精装）
- **页数**
- **丛书系列**
- 评分和评价人数（**内部参考，不写入给用户的笔记正文**）

#### 2e. 判断标准
```
✅ 通过条件（全部满足）：
  1. 译者姓名明确匹配
  2. 有大陆出版社（非台湾/香港）
  3. 出版年 ≥ 2000 年或该版本为2000年后再版
  4. 有ISBN号

❌ 淘汰条件（任一满足）：
  1. 无独立豆瓣条目
  2. 只有台版/港版（出版社含「天下」「遠流」「格林文化」「聯經」等）
  3. 只有旧版绝版（无2000年后再版记录）
  4. 该版本并非此书（同名不同书）
```

### 输出
对每个候选译者标注 ✅/❌，有完整出版信息。

### 例子：《爱的教育》豆瓣核验
```
王干卿 ✅ → 人民文学出版社2014版，天天读经典系列
夏丏尊 ✅ → 译林出版社2020+版，经典译林系列
田雅青 ✅ → 北岳文艺出版社2009版
徐力源 ✅ → 中国少年儿童出版社2011版
刘月樵 ✅ → 海豚出版社2023彩绘全译本
```

## 第3步：国图交叉验证（解决：确认这个译者版本是正式出版物且有馆藏）

### 原理
豆瓣可能收录一些"出版社不详"或"非正规出版物"的条目。国家图书馆OPAC（opac.nlc.cn）有大陆正式出版物最完整的馆藏记录，可以作为权威交叉验证。

### 操作流程

#### 3a. 用ISBN查国图
访问国图 OPAC：
```
http://opac.nlc.cn/F?func=find-b&find_code=ISB&request={ISBN}
```

#### 3b. 提取书目信息
从搜索结果中获取：
- **题名与责任**（确认书名和译者匹配）
- **出版项**（出版社、年份）
- **载体形态**（页数、尺寸）
- **中图分类号**
- **馆藏地点**（中文基藏/北区中文图书区等）

#### 3c. 判断标准
```
✅ 通过条件（全部满足）：
  1. 国图元数据中译者姓名与豆瓣一致
  2. 出版社与豆瓣一致
  3. 有馆藏记录

❌ 淘汰条件（任一满足）：
  1. 国图无馆藏记录
  2. 馆藏中的译者与预期不匹配（同名不同人）
  3. 实际出版年早于豆瓣标注（存在虚假信息）
```

## 第4步：多译者校验（解决：最终确定哪些书值得出评测）

### 操作
结合第2步和第3步的数据，对每本书做最终判断：

```
对于一本书，豆瓣核验通过的译者 ≥ 2人 → ✅ 进入正式候选池
对于一本书，豆瓣核验通过的译者 < 2人 → ❌ 剔除
```

### 实际操作中可能遇到的边界情况

| 场景 | 处理方式 |
|------|---------|
| 初始候选列了5位译者，核验后剩2位 | 保留，只要≥2人就行 |
| 初始候选列了3位译者，核验后剩1位 | 剔除，通知用户 |
| 1位译者有多种版本（如不同出版社、不同装帧） | 只算作1位译者，笔记中可推荐不同版本 |
| 合译者（如"沈国华+钱培鑫+曹德明 合译"） | 算作1个翻译组合进入候选 |
| 民国首译者新中国成立后再版 | 计算为1位译者（如赵元任译《爱丽丝漫游奇境》仍在印） |

### 输出
一份**最终校验通过清单**，每本书列出通过的译者和推荐版本信息。

### 实际案例：剔除记录

| 书名 | 原因 | 说明 |
|------|------|------|
| 格列佛游记 | 只剩张健1人 | 初候选3人，核验后仅张健有2000年后在版 |
| 了不起的狐狸爸爸 | 只剩代维1人 | 徐朴/林良/张樱均无大陆2000年后单本 |
| 窗边的小豆豆 | 只剩赵玉皎1人 | 朱自强版无独立单本 |
| 海蒂 | 只剩邵灵侠1人 | 杨曦红/郑高凤均无2000年后独立版本 |
| 蓝箭 | 0人 | 任溶溶/李依琳均未找到版本 |
| 杜立德医生 | 0人 | 全部译者存疑 |

## 第5步：译本评测（解决：出具体推荐方案）

### 5a. 选一本开始写
从候选池中由用户决定先写哪一本。

### 5b. 译本资料整理
基于已核验的数据，为多个译者整理以下信息：
- 译者背景（老翻译家/新生代/合译者）
- 主要出版社/版本
- 译文风格大致判断

### 5c. 撰写评测笔记

#### 写作模板
```
1. 每本书推荐4-5个译本
2. 每个译本一句话点评风格
3. 「省流版」总结，按不同需求推荐
4. 不写具体原文译文对照
5. 最后带一句互动
6. 不开头写评分/评价人数
7. 结尾加来源说明
```

#### 推荐维度
从以下角度帮用户选择：
| 维度 | 说明 | 示例 |
|------|------|------|
| 语感/流畅度 | 读起来顺不顺 | "语感最流畅，一口气读完" |
| 文学性 | 用词精不精美 | "翻译大家，语言有质感" |
| 准确性 | 有没有乱删改 | "逐字逐句忠实原文" |
| 版本可及性 | 现在还能不能买到 | "最新再版，当当京东都有" |
| 儿童友好 | 孩子读得懂吗 | "口语化，适合小学生" |
| 性价比 | 价格如何 | "定价不到20元" |

#### 来源说明
每篇笔记正文最后加：
```
━━ 数据来源 ━━
✅ 豆瓣图书页、国家图书馆OPAC
```

#### 禁止行为
- ❌ 不出现豆瓣评分、评价人数
- ❌ 不编造译本、不道听途说
- ❌ 不写具体原文与译文逐句对照
- ❌ 不做营销号腔调

### 输出
一篇完成的小红书笔记（不含发布，需用户确认后发布）。

## 第6步：竞品调研（解决：写出真正契合家长痛点的评测）

### 做什么
在小红书、豆瓣书评等平台，搜索目标书籍，看看家长们／读者们实际在讨论什么问题。

### 操作
搜索关键词组合：
```
{书名} 翻译 不好
{书名} 哪个版本 好
{书名} 买哪个 版本
{书名} 译本 对比
{书名} 适合 孩子 读
```

### 需要捕捉的痛点和话题
- 哪个译本**孩子读得下去**（可读性）
- 哪个译本有**删改**（完整性）
- **不同年龄段**怎么选（学龄前 / 小学低年级 / 小学高年级）
- 哪个版本**装帧好**（印刷质量、插图）
- 哪个版本**性价比高**
- 哪个出版社的版本**质量稳定**

### 输出
捕捉到的关键信息，融入评测正文——帮助用户写一篇"懂家长心声"的笔记，而非干巴巴的学术对比。

## 数据模型（给 Web 应用参考）

### Book 书籍
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| title | string | 书名 |
| author | string | 原作者 |
| isClassicChildren | boolean | 是否属于经典儿童文学 |
| candidateStatus | enum | candidate / completed / passed |
| passReason | string | 如果passed，记录原因 |

### Translator 译者
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| name | string | 译者姓名 |
| bookId | string | 关联的书籍 |
| verificationStatus | enum | pending / verified / rejected |
| rejectionReason | string | 淘汰原因 |
| doubanInfo | object | 豆瓣核验结果 |
| nlcInfo | object | 国图核验结果 |

### DoubanInfo
| 字段 | 类型 | 说明 |
|------|------|------|
| subjectId | string | 豆瓣 subject ID |
| publisher | string | 出版社 |
| publishYear | number | 出版年 |
| isbn | string | ISBN |
| price | string | 定价（可能缺失） |
| binding | string | 装帧（平装/精装） |

### NlcInfo
| 字段 | 类型 | 说明 |
|------|------|------|
| isbn | string | ISBN |
| hasCollection | boolean | 是否有馆藏 |
| collectionLocation | string | 馆藏地点 |

### Note 评测笔记
| 字段 | 类型 | 说明 |
|------|------|------|
| bookId | string | 关联书籍 |
| recommendedTranslators | array | 推荐的译者及版本 |
| summary | string | 省流版总结 |
| publishedAt | date | 发布时间 |
| platform | string | 发布平台（如小红书） |

## 摘要：每步解决的问题

| 步骤 | 问题 | 答案 |
|------|------|------|
| 第0步 | 什么书值得做？ | 外国经典儿童文学 + 多译者 + 2000年后在版 |
| 第1步 | 从哪找候选？ | 经典书单 → 标注译者状况 → A类/B类分流 |
| 第2步 | 译者版本真的存在吗？ | 豆瓣图书页核验 ISBN、出版社、出版年 |
| 第3步 | 是正式出版物吗？ | 国图OPAC 交叉验证馆藏信息 |
| 第4步 | 够资格出评测吗？ | 多译者 ≥2 人 → 通过；<2 人 → 剔除 |
| 第5步 | 具体怎么推荐？ | 按模板写评测笔记，从语感/文学性/可及性等多维度推荐 |
| 第6步 | 读者关心的点是什么？ | 搜索小红书/豆瓣，捕捉家长的讨论和痛点 |
